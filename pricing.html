          FREQUENTLY ASKED QUESTIONS
          

            Panduan & Pertanyaan Umum
          

        


        

          
          

            
              Bagaimana skema pembayaran dan proses pengerjaan?
              expand_more
            
            

              Skema pembayaran menggunakan sistem 50% Down Payment (DP) di awal untuk inisiasi sprint, dan 50% pelunasan setelah website selesai di-review, diverifikasi, dan siap go-live. Penyerahan source code dan akses admin diberikan penuh setelah pelunasan.
            

          


          

            
              Berapa lama estimasi pengerjaan setiap proyek?
              expand_more
            
            

              Landing Page single-page umumnya selesai dalam 1–2 hari kerja. Company Profile multi-halaman selesai dalam 3–5 hari kerja. Aplikasi web kustom, sistem booking, atau integrasi database membutuhkan 7–14 hari kerja tergantung kesiapan materi.
            

          


          

            
              Apakah domain dan hosting ditanggung oleh klien?
              expand_more
            
            

              Untuk Paket Business Platform (Tier 02), domain .com 1 tahun sudah termasuk gratis. Untuk deployment, kami menggunakan infrastruktur cloud modern (Vercel/Cloudflare) yang gratis, aman dengan SSL otomatis, dan berkecepatan global.
            

          


          

            
              Apakah saya mendapatkan akses penuh ke source code?
              expand_more
            
            

              Ya, 100% source code, aset desain, dan konfigurasi repositori GitHub akan diserahkan kepada Anda. Tidak ada biaya sewa tersembunyi atau keterikatan vendor.
