## 🌟 Key Highlights & Architecture

- **🪐 3D WebGL Cosmic Engine (Three.js)**:
  - Custom GLTF Tesseract model with DRACO mesh compression and PBR roughness/metalness materials.
  - Multi-layer celestial starfield (1,600 stars) with real stellar spectra and floating cosmic crystal asteroids.
  - Volumetric depth fog, glowing dual harmonic orbital rings, and dynamic lighting rigs.
- **⚡ Silky 60fps Auto-Snap Scroll System (GSAP & ScrollTrigger)**:
  - Locked full-page cinematic navigation engine with smooth gliding deceleration.
  - Responsive coordinate matrix calibrated across desktop, tablet, and mobile viewports.
- **🖼️ 100% WebP Optimized Assets**:
  - Over 90% bandwidth reduction with asynchronous image decoding (`decoding="async"`) for zero-stutter performance.
- **🎯 Enterprise-Grade Top-1 SEO**:
  - Schema.org JSON-LD structured data (`Person`, `WebSite`, `ProfilePage`, `CollectionPage`).
  - Automated `sitemap.xml`, `robots.txt`, OpenGraph HD previews, and geographic targeting for Medan, Indonesia.
- **🌐 Multilingual Engine**:
  - Instant client-side English & Indonesian translation dictionary.
- **📱 Standalone Project Case Studies & Code Playground**:
  - Markdown README documentation renderer powered by Marked.js & Highlight.js.
  - Dynamic GitHub API integration for real-time repository stats and commit activity heatmap.

```text

├── public/

```

## 🚀 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/Apisikma123/porto-aga.git
cd porto-aga
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
