# Caveman Quick Reference

- `/caveman lite` ? Drop filler, keep grammar.
- `/caveman full` ? Standard caveman mode (default, ~65% token cut).
- `/caveman ultra` ? Maximum compression.
- `/caveman off` ? Return to normal conversational mode.
- `/caveman-commit` ? Terse Conventional Commit message.
- `/caveman-review` ? One-line actionable code review findings.
- `/caveman-compress` ? Compress rules / memory documentation.
