# Caveman Compress

Compress text, rules, and memory files into high-density tokens.

## Rules
- Strip passive voice, repetitive examples, and boilerplate headers.
- Convert multi-paragraph guidelines into compact bullet lists and decision tables.
- Retain exact invariant rules, security boundaries, and syntax requirements.
